**Changes versus upstream, and why.**
- Runners: GitHub-hosted and ICR instead of Blacksmith; no deps/_build/tracker cache (cold by design), so the tracker is always built and the `paths-filter` step, whose only effect is to skip that build, is dropped.
- `.tool-versions` read by a shell step (`awk`) instead of `marocchino/tool-versions-action` — one third-party action fewer, same values.
- `ImageOS` derived from `/etc/os-release` (`ubuntu26`) when the environment does not define it: erlef/setup-beam's documented requirement on self-hosted runners; GitHub's images define it (`ubuntu24`, `ubuntu26`) and are left untouched.
- MinIO image: `minio/minio` is no longer on Docker Hub (hub.docker.com returns 404 for the repository and the registry 401, checked 2026-09-19); upstream's `make minio` keeps working on Blacksmith only through its registry mirror. Here the release quay.io's `latest` tag points to, `quay.io/minio/minio:RELEASE.2025-09-07T16-13-09Z@sha256:14cea493d9a34af32f524e538b8346cf79f3321eff8e708c1e2960462bd8936e`, is pulled by digest and tagged `minio/minio:latest` locally, so the Makefile's `docker run … minio/minio …` runs unchanged with a pinned image on every leg.
- `MINIO_HOST_FOR_CLICKHOUSE`: upstream hard-codes `172.17.0.1`, the Docker default-bridge gateway through which the ClickHouse service container reaches MinIO's port published on the host (`lib/plausible/s3.ex` rewrites the S3 URL host with it); the workflow reads that gateway from the daemon (`docker network inspect bridge`) and falls back to `172.17.0.1` — identical on GitHub's images, robust if ICR's daemon uses another address pool.
- Six shards as one `mix test` (above): the union of the cell's shards; the run uses all cores (`max_cases = 2 × schedulers`) as each shard does.
- `mix test` output tee'd to a file (`shell: bash`). `timeout-minutes: 90` (upstream: none).

**Third-party actions needed.** `erlef/setup-beam@v1` (upstream uses it at v1.24.1). Self-hosted Ubuntu 26.04: supported — README compatibility table: `ubuntu-26.04`, Erlang/OTP 26–29, x86_64/arm64 ✅ (OTP 28.5.0.5 is downloaded from builds.hex.pm for the `ubuntu-26.04` target, Elixir 1.20.4-otp-28 as a precompiled archive); README "Self-hosted runners": `ImageOS` must be set to one of `ubuntu22`, `ubuntu24`, `ubuntu26` (and the arm64 variants) — set by the workflow when missing. It also installs hex and rebar3 (its defaults), which `mix deps.get` needs. Dropped third-party actions: `marocchino/tool-versions-action`, `dorny/paths-filter`, `actions/cache`.

**Expected duration.** Upstream has no GitHub-hosted runs: the job runs on Blacksmith 4-vCPU runners with warm deps/_build/tracker caches, one sixth of the suite per job. `Build and test (test, postgres:18)` shard jobs of the last 6 successful runs (2026-09-07: 34137264100, 34118273385, 34118026078, 34117932437, 34115433391, 34105598684; 35 shard jobs): min 69 s, median 77 s, max 96 s — of which the test run itself is a few tens of seconds. Cold (this workflow: deps download, full `mix compile --warnings-as-errors` of deps and app, tracker `npm install` and compile, migrations on both databases, tzdata, MinIO, the whole suite): expect roughly 12–20 min on 4 vCPU, 20–35 min on `icr-2c`.

**Memory/disk risks.** ClickHouse server 1–2 GiB, PostgreSQL 18 small, BEAM compile 1.5–2.5 GiB, the test run (`pool_size: schedulers` Postgres sandboxes, ClickHouse queries) 1–2 GiB → fits `icr-2c` (8 GiB). Disk: `deps` + `_build` 2–3 GB, `tracker/node_modules` ~0.5 GB, images ~1.5 GB. Host ports used: 5432 and 8123 (services), 10000/10001 (MinIO, `-p` on the host) — must be free on the runner VM.

**What may fail on the ICR image, fix applied.** (a) erlef/setup-beam without `ImageOS` → set from `/etc/os-release`. (b) `minio/minio` pull from Docker Hub → quay.io by digest, tagged locally (needed on GitHub-hosted runners as well). (c) ClickHouse → MinIO reachability if the default bridge gateway is not `172.17.0.1` → gateway read from the daemon. (d) Node/npm for the tracker build: taken from the image (GitHub's runner-image Node, ICR's toolset Node), as upstream does on Blacksmith; version printed in Runner facts. (e) `docker` CLI needed for `make minio` and the gateway lookup — present on both sides.
